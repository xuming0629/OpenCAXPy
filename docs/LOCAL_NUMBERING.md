# OpenCAXPy local numbering

## Global and local IDs

`mesh.cells[cell_id, local_node_id]` maps a local node ID to a global node ID.

`cell2edge[cell_id, local_edge_id]` maps a local edge ID to a global edge ID.

Neither row is sorted after construction. Column position carries local topology.

## Triangle3

For a counter-clockwise cell:

```text
cell = [v0, v1, v2]
```

the local edges are:

```text
local edge 0 = (v1, v2), opposite local node 0
local edge 1 = (v2, v0), opposite local node 1
local edge 2 = (v0, v1), opposite local node 2
```

Thus:

```python
TRIANGLE3.local_edges == ((1, 2), (2, 0), (0, 1))
```

For structured right triangles generated by `triangle_rectangle`, local node 0
is the right-angle vertex and the nodes are counter-clockwise.

## Canonical global edge

A global edge is stored canonically as `(min(node_a, node_b), max(...))`.
This sorting is used only to deduplicate global edges. It does not reorder
`cell2node` or `cell2edge`.

`mesh.cell_to_edge_sign()[cell_id, local_edge_id]` is:

- `+1`: directed local edge matches the global edge direction.
- `-1`: directed local edge is opposite to the global edge direction.
